# Multi-Terrain-VEX-Rover-Phase-2

 **Phase 2 Upgrades & Precision Stopping Challenge

* **Task Objective:** Autonomous precision navigation. The rover must traverse a 25-meter course over varied terrain and brake autonomously as close to a target cube as possible without contacting it.
* **Mechanical Enhancements:**
  * **Articulating Sub-Treads (Flippers):** Added front-mounted auxiliary tracked assemblies to improve terrain traversal, climb over obstacles, and maintain continuous ground contact.
  * **Center of Gravity Optimization:** Reconfigured component placement to balance pitch and roll stability over bumps.
* **Autonomous Navigation & Control:**
  * Implemented real-time sensor feedback (limit switches / proximity logic) via the VEX microcontroller.
 
  * RESULT: The Rover was able to stop exactly 20mm away from the cube as we succeeded.
 
  * The project was really fun and engaging, the calculations and multiple tests we conducted to the end result were the best part for me, the code took a long time to construct as we learned the sample, debugged and continued to try and test until it worked. This was part 2 May 5th of 2026, and our modifications helped significantly with the end result.
